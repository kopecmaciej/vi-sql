# Release v0.1.4

SQL formatting, error modal copy, and escaping connection/options pages.

## Features

- **SQL formatting** — format the query in the editor in place with `gf` (vim mode) or `Ctrl+f` (normal mode), also available from the actions modal. ([#58](https://github.com/kopecmaciej/vi-sql/pull/58))
- **Copy button on error messages** — the error modal now includes a button to copy the error text to the clipboard. ([#52](https://github.com/kopecmaciej/vi-sql/issues/52))

## Fixes

- **Autocomplete inside quotes** — autocomplete for columns, schemas, and tables now behaves correctly when the cursor is inside quotes. ([#57](https://github.com/kopecmaciej/vi-sql/pull/57))
- **Focus after delete error** — focus is now restored correctly after a failed row delete. ([#59](https://github.com/kopecmaciej/vi-sql/issues/59))
- **Escaping connection/options pages** — leaving the connection or options page no longer wipes the active session. ([#60](https://github.com/kopecmaciej/vi-sql/issues/60))
