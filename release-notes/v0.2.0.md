# Release v0.2.0

Oracle database support, focus stack fix, and config lifecycle improvements.

## Features

- **Oracle driver (by @ericschoville, [#64](https://github.com/kopecmaciej/vi-sql/pull/64))** — connect to Oracle databases with full query, schema browsing, and pagination support.

## Fixes

- **Focus restoration from nested modals** — closing the value viewer inside a peeker modal now correctly restores focus to the peeker instead of dropping back to the table. ([#65](https://github.com/kopecmaciej/vi-sql/pull/65))
- **Options page cancel** — cancelling the options page no longer overwrites the active config with an empty draft. ([#63](https://github.com/kopecmaciej/vi-sql/issues/63))
- **Manager shutdown safety** — the manager's `Stop()` method now uses `sync.Once` so the close logic runs at most once, preventing panics on rapid shutdown sequences. ([#66](https://github.com/kopecmaciej/vi-sql/issues/66))
