# Release v0.1.2

New copy actions, a more flexible config path, and a terminal paste fix.

## Features

- **Copy row as JSON or CSV** — two new data-view actions copy the selected row in JSON or CSV format. Defaults are `yrj` / `yrc` in vim mode and `Alt+j` / `Alt+c` in normal mode, and both are available from the actions modal. ([#47](https://github.com/kopecmaciej/vi-sql/pull/47))
- **Longer keybinding sequences** — the keybinding editor now accepts sequences of two or more runes (previously capped at two), enabling chords like `yrj`. ([#47](https://github.com/kopecmaciej/vi-sql/pull/47))
- **`--config` accepts a directory** — passing a directory to `--config/-c` now resolves to `config.yaml` inside it, instead of requiring the full file path.

## Fixes

- **Pasting with the terminal paste key** — bracketed-paste input from the terminal now works correctly; updated to a patched tcell fork. ([#46](https://github.com/kopecmaciej/vi-sql/issues/46))

## Changes

- **Confirm default changed to `Ctrl+s`** — the normal-mode Confirm binding no longer defaults to `Ctrl+Enter`, which doesn't register in some terminals and tmux; both modes now default to `Ctrl+s`.
