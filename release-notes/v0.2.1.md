# Release v0.2.1

Patch release with a history modal improvement and two stability fixes.

## Features

- **Query duration in history** — the history modal now shows how long each query took to run, next to the timestamp. ([d3c93d2](https://github.com/kopecmaciej/vi-sql/commit/d3c93d2))

## Fixes

- **Crash after entering master password** — restoring focus after the master password prompt no longer panics when the focus stack is empty. ([#68](https://github.com/kopecmaciej/vi-sql/pull/68))
- **Paste while autocomplete is on** — pasting text into the query editor no longer interferes with the autocomplete suggestion; the tview dependency is updated to handle this case. ([#66](https://github.com/kopecmaciej/vi-sql/issues/66))

## Thanks

Thanks to everyone who contributed to this release.
