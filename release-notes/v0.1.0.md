First public release of vi-sql — a terminal UI for SQL databases built for keyboard-driven workflows.

## Supported databases

PostgreSQL · SQLite · MySQL · MariaDB · CockroachDB · SQL Server

## Highlights

### Vim mode
Full vim-style navigation across the entire UI — `hjkl`, sequence keys (`gg`, `dd`, `gd`, `gr`), visual and visual-line selection, and insert/normal mode in the SQL editor. Every keybinding is remappable.

### SQL editor
Syntax highlighting, context-aware autocomplete (tables, columns, keywords), query history per connection, and optional `$EDITOR` integration for writing queries in your preferred editor.

### Table & query modes
Browse any table directly from the schema tree. Table mode exposes full CRUD — inline edit, full-form edit, add, duplicate, delete rows. Query mode runs arbitrary SQL. Both support column hiding, visual multi-row selection, and clipboard copy.

### Schema browser
Explore schemas, tables, columns, indexes, and DDL. Create, rename, and drop objects from keybindings or the action modal. Follow foreign keys with `gd`; find all references with `gr`.

### EXPLAIN viewer
Run `EXPLAIN` or `EXPLAIN ANALYZE` on any query and inspect the plan with cost and timing breakdown.

### Import / Export
Export results as CSV, JSON, SQL INSERT, or Markdown. Import CSV files into any table.

### MCP server
Built-in HTTP MCP server lets AI tools (Claude Code, Cursor, etc.) browse your schema and draft queries directly in the editor. Query execution is opt-in per security level.

### Encrypted connections
Passwords encrypted with AES-256-GCM. Choose between OS keyring, master password, or environment variable — or disable encryption entirely.

### Themes
Multiple built-in themes with full YAML customisation.
