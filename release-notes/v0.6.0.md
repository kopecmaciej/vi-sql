# Release v0.6.0

<p align="center">
  <img src="https://github.com/kopecmaciej/vi-sql/blob/master/assets/logo.svg"/>
</p>

Minor release adding per-connection read-only mode, a reworked DDL pane, and vim sequence hints in the footer.

## Features

- **Per-connection read-only mode** — a Read-only checkbox in the connection form turns the connection into a safe inspection mode: every mutating operation (insert, update, delete, DDL changes, table and column renames) is rejected with a clear error, while browsing and running queries work as usual.
- **Reworked DDL pane** — the DDL pane is now a read-only SQL editor, so table and view definitions can be scrolled, searched, and copied, with its keybindings shown in the footer. Toggling the pane with `p` now moves focus to it when it opens and back to the structure table when it closes. ([#87](https://github.com/kopecmaciej/vi-sql/pull/87))
- **Quick keys for structure and indexes** — jump straight to a table's structure with `gS` (`Alt+S`) or its indexes with `gI` (`Alt+I`) from anywhere.
- **Copy column details** — copy the selected column's name with `yc` (`C`) or its full definition (type, nullability, constraints) with `yy` (`c`) from the structure view.
- **Footer sequence hints** — after pressing a vim sequence prefix like `y` or `d`, the footer now shows every continuation available for the focused component (e.g. `y` → `yy`, `yc`, `yrj`), so multi-key chords are discoverable. Count prefixes like `2d` are handled.

## Fixes

- **Footer data race** — fixed a race between the footer's event goroutine and the draw loop that could corrupt the key override state. ([a2ae0ac](https://github.com/kopecmaciej/vi-sql/commit/a2ae0ac))
