# Release v0.1.3

Views in the schema tree, XLSX export, smarter autocomplete quoting, and Windows support.

## Features

- **Views in the schema tree** — database views now appear in the schema tree alongside tables. Opening a view opens a read-only data tab; the structure tab shows the view definition. ([#49](https://github.com/kopecmaciej/vi-sql/pull/49))
- **XLSX export** — the export modal now includes an XLSX option alongside CSV and JSON. ([#8c97391](https://github.com/kopecmaciej/vi-sql/commit/8c97391))
- **Dialect-aware autocomplete quoting** — autocomplete in the query editor and filter/order input bars now quotes identifiers using the correct syntax for each backend (`"` for Postgres/SQLite, `` ` `` for MySQL/MariaDB, `[` `]` for SQL Server). BuildScope is now scoped to the cursor position and digit-starting column names are quoted correctly. ([#50](https://github.com/kopecmaciej/vi-sql/pull/50))
- **Windows install script** — a PowerShell install script is now included for Windows users. The default log path now uses the OS temp directory on all platforms. ([#56](https://github.com/kopecmaciej/vi-sql/pull/56))

## Fixes

- **Opening the same tab twice** — opening a table or query that already has an open tab now focuses the existing tab instead of creating a duplicate. ([#49](https://github.com/kopecmaciej/vi-sql/pull/49))
- **Copy as JSON nested formatting** — copying a row as JSON now correctly formats nested JSON values instead of double-encoding them.
